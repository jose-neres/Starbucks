## 📌 Sobre o Projeto

O **Starbucks** é um projeto Front-End desenvolvido com o objetivo de recriar uma experiência visual inspirada na marca Starbucks, explorando conceitos de design, organização de elementos e construção de interfaces modernas.

A aplicação apresenta uma página com foco em apresentação de produtos, utilizando uma composição visual atrativa, elementos gráficos e uma estrutura organizada para proporcionar uma navegação simples e agradável.

Este projeto foi desenvolvido como prática de aprimoramento em desenvolvimento web, aplicando conceitos de **HTML, CSS e JavaScript** na criação de uma interface completa.

## 🤖 Assistente Virtual - Giovana Bot

O projeto conta com a integração da **Giovana Bot**, uma assistente virtual desenvolvida com o objetivo de auxiliar os usuários durante a escolha dos pedidos.

A IA foi criada para oferecer suporte na tomada de decisão, sugerindo opções e orientando o usuário conforme suas preferências, tornando a experiência de navegação mais interativa e personalizada.

### Funcionalidades da Giovana Bot:

✔ Auxílio na escolha de pedidos
✔ Orientações durante a navegação
✔ Sugestões personalizadas conforme as opções disponíveis
✔ Interação com o usuário através de uma experiência conversacional

A integração da assistente virtual demonstra a aplicação de conceitos de **Inteligência Artificial (IA)** em interfaces web, proporcionando uma experiência mais próxima de um atendimento digital real.
